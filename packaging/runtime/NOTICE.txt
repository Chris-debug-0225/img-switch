Runtime modification notice

This distribution contains a modified copy of the CPython runtime. The only
modification is removal of one nonessential example line from the splitroot
documentation embedded in the runtime and its standard library bytecode.
Absolute build-directory prefixes in CPython extension-module source-file
diagnostic strings are replaced with equal-length placeholders; debug symbols
are removed from macOS extension modules. The original copyright and license
notices for CPython are included alongside this notice.
