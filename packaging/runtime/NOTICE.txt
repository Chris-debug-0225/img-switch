Runtime modification notice

This distribution contains a modified copy of the CPython runtime. A
nonessential example line is removed from splitroot documentation in the
runtime and standard library bytecode. Absolute build-directory prefixes in
CPython source-file diagnostic strings are replaced with equal-length
placeholders; debug symbols are removed from macOS runtime libraries and
extension modules. In the frozen macOS runtime, the VPATH build-tree setting is
changed to "." to avoid distributing the original build directory. The original
copyright and license notices for CPython are included alongside this notice.
